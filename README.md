## Claude + DuckDB backend

The configurable financial-coach pipeline is in [backend](backend/README.md).
It includes CSV/DuckDB schema adapters, customer-scoped financial tools, a bounded
direct Anthropic API agent, FastAPI endpoints, tests and a Google Cloud Run container.
Follow the [deployment guide](backend/DEPLOYMENT.md) for the API key smoke test and Cloud Run setup.
The existing mobile webapp in `ui-demos` remains unchanged.
